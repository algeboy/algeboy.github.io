18.1 A short library of common rules

The following list of rules can be found in many logics. Some are more controversial than others but without some rules it is difficult to make any progress.

Transitive

By far the most common rule is transitivity. \[ \tag{Transitivity} \begin{array}{rc} P &\vdash Q\\ Q &\vdash R\\ \hline P &\vdash R \end{array} \]

Exchange

Next in line is exchange which says in effect that we need not worry about the order of our premises. In temporal logics (logics that deal with time) and spacial logics (logic dealing with location) this sort of rule may in fact be replaced by ones that pay attention to the need for sequencing. \[ \tag{Exchange} \frac{P,Q \vdash R}{Q, P \vdash R} \]

Identity

Except for systems that may need to meticulously tracking resources, it is generally accepted that we a premise can justify itself and that one appearance of the premise is as good as several. \[ \tag{Identity} P \vdash P \] \[ \tag{Contraction} \frac{ P, P \vdash Q }{ P \vdash Q } \]

Monotonicity

For many arguments it is ok to include a premise that never gets used. \[ \tag{Monotonicity} \frac{ P \vdash Q }{ P,R \vdash Q } \] This rule also goes by the name thinning or weakening.

While monotonicity is a common rule in math and science there are considerable situations where this rule is rejected. Such non-monotonic logics are often used when detailing how our knowledge evolves with new evidence. We begin with default judgments but upon learning of new information \(R\) we need to adapt. This is a common requirement in error analysis, probability, and the more general subject of a posteriori analysis (the logic that deals with empirical origins of facts).
