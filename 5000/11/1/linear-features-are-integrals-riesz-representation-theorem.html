11.1 Linear Features are Integrals (Riesz Representation Theorem)

In computation, information can often be minimized to a number. You might want to argue we should consider lists of numbers too, but as we are looking into the building blocks, the smallest we should go is extracting a single number as our information. The industry has given this asset the name “feature”.

Definition of Features

A feature on a set of data is a function (or in computational syntax def feature( x : Data ) : Float), which assigns a decimal number or an infinity to every point.

In practice and computation we may need to get by with an approximation known as a partial feature which is a function that attempts to assign such a value but may on some inputs be undefined, i.e. , equivalently def feature( x : Data ) : Float?. (Recall is away to assign an output of nothing to a failed evaluation.)

Integrals as Features

Perhaps the most common feature in a collection of numbers is that average. However context is important to understand what “average” we intend. We can see the impact by looking 40 years of oil prices.

Above we show the crude oil prices from 1986-2026 in dollars. Identified in the graphic the average, $51.02. It is a large sum scaled by the total number of daily prices.

(The shaded region shows the standard deviation, roughly how much change is considered typical in a statistically noisy situation.)

Crude Oil Adjusted for Inflation

Now let’s include some subject matter expertise. The value of the dollar changes over time as well. So the meaning of these prices changes. What cost $100 in 1986 is not the same as in 2026. Below is a new graph adjusted for this effect known as “inflation”.

Here the average jumps to $73.87. And it truly is a different formula

This is getting complicated. We might do better to think of this as a new kind of sum, one that uses intervals of inflation instead of days as its steps.

Even familiar data like “averages” can benefit from complexities such as weighting values. In our oil prices this was done to adjust for inflation. In grades this is done to weight exams differently for homework. Both give us a clues about the meaning of the data. And both are a form of integral.

Integrals as features.

When our data consists of numbers (f(i)) over a range of values (iI), we can attempt to create a single number adding up the values. If the list is not finite we can take an integral as a number instead. And if we want a more nuanced measure that includes how we should weight the inputs (e.g. as we did with inflation) we can simply modify how we measure (). So integrals are by design convenient features.

The weighted average and Expectation

Suppose our data is a list of decimal numbers (a_1,, a_n). We can take the average, which will put a number to the data, i.e. the average is a feature.

Now because the average is also a sum we can write it as an integral where we weight our measure by 1/n, the total number of samples. That is how the common average works.

Yet we sometimes we want data to be weighted. Perhaps homework scores count for 35% and exams for 55%. We could still use an integral but we would need to re-weight things.

A weighted average is just a new feature. It is also just a different integral. In fact this whole idea has spread to giving “average” a new name, called “Expectation”. That means an average created as an integral.

Linear Features

In a phrase, a feature is linear if “it is distributed amongst summands.” But what does this actually mean? Remember we are only looking here at data (f) that are already numbers. That means we can already talk about addition. So we cannot only add data (f) to data (g), we can also add their features (F(f)+F(g)). So how different is (F(f+g)) from (F(f)+F(g))? Continuous Features

A final useful condition on features is the ability to use approximations. This is because data collection is often too fragile to get the same exact number over and over every time we re-measure. We realistically need to accept that our data will be approximate. But if the features of approximation are radically different then we simply cannot use those features. It will be unreliable. To avoid this the most stable features work well with approximations in the following sense.

Implications

Let us summarize.

  • Integrals give use features.
  • All features can be seen as evaluating certain integrals.
  • So in a loose sense integrals are responsible for all features.

The implication is both practical and theoretical.

  • On the practical side we can make really good software and hardware to compute integrals. What are integral again? Giant sums. Great, make hardware that can add lots of numbers very fast. GPUs are the world leaders in this space at the moment.
  • On the theory side having one concrete description of features as integrals helps us give precise facts about what is possible, prove what is impossible, and link data science problems to a very long history of mathematics where new ideas have a good chance of surfacing.
