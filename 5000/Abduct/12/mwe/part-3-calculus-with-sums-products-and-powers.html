Measuring lengths, areas, and volumes

Let’s focus on a special case of measurement where we measure like a carpenter, that is, we look at the starting point and the ending points and we assume everything in between is part of the length. This means we only need to know how to measure intervals ((a,b)= {xa<x<b}). The standard Lebesgue interval measure for this is

\[\displaystyle m\Big((a,b)\Big) := b-a\]%255CBig)%2520%253A%253D%2520b-a?scale=1)

(m((x_1,x_2)(y_1,y_2)) = (x_2-x_1) (y_2-y_1) = m((x_1,x_2))m( (y_1,y_2)))

*Newton-Leibniz’s Interval measurement Theorem.

For the Lebesgue integral measure \[m\Big((a,b)\Big)=b-a\]%255CBig)%253Db-a?scale=1) and Lebesgue measurable function \[f:(a,b)\to [-\infty,\infty]\]%255Cto%2520%255B-%255Cinfty%252C%255Cinfty%255D?scale=1) then for \[a<x_1<x_2<b\]

\[\displaystyle F(x_2)-F(x_1) = \int_{(x_1,x_2)} f\, dm\]-F(x_1)%2520%253D%2520%255Cint_%257B(x_1%252Cx_2)%257D%2520f%255C%252C%2520dm?scale=1) where \[\displaystyle F(x) := \int_{(a,x)} f\, dm\]%2520%253A%253D%2520%255Cint_%257B(a%252Cx)%257D%2520f%255C%252C%2520dm?scale=1).

Said in the more classical interval notation this means

\[\displaystyle F(x)\bigg|_{x_1}^{x_2}=F(x_2)-F(x_1) = \int_{x_1}^{x_2} f(t) \, dt\]%255Cbigg%257C_%257Bx_1%257D%255E%257Bx_2%257D%253DF(x_2)-F(x_1)%2520%253D%2520%255Cint_%257Bx_1%257D%255E%257Bx_2%257D%2520f(t)%2520%255C%252C%2520dt?scale=1) wherever \[\displaystyle F(x) := \int f(t)\, dt\]%2520%253A%253D%2520%255Cint%2520f(t)%255C%252C%2520dt?scale=1), equivalently \[\displaystyle \frac{dF}{dx}=f(x)\]?scale=1).

Proof Lebesgue \[\vdash\] Newton-Leibniz**

We want to learn about ({(x_1,x_2)} f, dm) in terms of (F(x)={(a,x)} f, dm). So we can start with

\[\begin{aligned} F(x_2) & = \int_{(a,x_2)} f\, dm & \text{ break into disjoint intervals}\\ & = \int_{(a,x_1)\sqcup (x_1,x_1)\sqcup (x_1,x_2)} f\,d m & \text{measure on disjoint intervals}\\ & = \int_{(a,x_1)}f\, dm + \int_{[x_1,x_1]} f\,dm + \int_{(x_1,x_2)} f\,d m & \text{notice }\begin{array}{c}m([x_1,x_1])=0\\ F(x_1)=\int_{(a,x_1)} fdm\end{array}\\ & = F(x_1) + 0 + \int_{(x_1,x_2)} f\,d m. \end{aligned}\]%2520%2526%2520%253D%2520%255Cint_%257B(a%252Cx_2)%257D%2520f%255C%252C%2520dm%2520%2520%2526%2520%255Ctext%257B%2520break%2520into%2520disjoint%2520intervals%257D%255C%255C%250A%2526%2520%253D%2520%255Cint_%257B(a%252Cx_1)%255Csqcup%2520(x_1%252Cx_1)%255Csqcup%2520(x_1%252Cx_2)%257D%2520f%255C%252Cd%2520m%2520%2526%2520%255Ctext%257Bmeasure%2520on%2520disjoint%2520intervals%257D%255C%255C%250A%2526%2520%253D%2520%255Cint_%257B(a%252Cx_1)%257Df%255C%252C%2520dm%2520%252B%2520%255Cint_%257B%255Bx_1%252Cx_1%255D%257D%2520f%255C%252Cdm%2520%252B%2520%255Cint_%257B(x_1%252Cx_2)%257D%2520f%255C%252Cd%2520m%2520%2526%2520%255Ctext%257Bnotice%2520%257D%255Cbegin%257Barray%257D%257Bc%257Dm(%255Bx_1%252Cx_1%255D)%253D0%255C%255C%2520F(x_1)%253D%255Cint_%257B(a%252Cx_1)%257D%2520fdm%255Cend%257Barray%257D%255C%255C%250A%2526%2520%253D%2520F(x_1)%2520%252B%25200%2520%252B%2520%255Cint_%257B(x_1%252Cx_2)%257D%2520f%255C%252Cd%2520m.%250A%255Cend%257Baligned%257D?scale=1)

Now we just solve for the term we want to know about

\[\displaystyle \int_{(x_1,x_2)} f\, dm = F(x_2)-F(x_1)\]%257D%2520f%255C%252C%2520dm%2520%253D%2520F(x_2)-F(x_1)?scale=1).

* Newton-Leibniz’ Can Fail for non-interval measures: Counting \[\not\vDash\] Newton-Leibniz

Now let’s change measures just to demonstrate that this claim is very much about the condition of the interval measure. We need only create a model (example) where the claim fails, so this is a \[\vDash\] situation. Let us use the function (f(x)=x) and choose (a=0<x_1=1<x_2<2).

\[\begin{aligned} \int_{(1,2)} x\, d\mu & = 0 & \text{ because }\mu\Big((1,2)\Big)=0\\ F(2) - F(1) & = \int_{(0,2)} x\, d\mu - \int_{(0,1)}x \, d\mu \\ & = \int_{[1,1]} x\,d\mu & \text{because }\mu((0,1))=0=\mu((1,2)), \text{ and} \mu([1,1])=1\\ & = 1 \end{aligned}\]%257D%2520x%255C%252C%2520d%255Cmu%2520%2526%2520%253D%25200%2520%2526%2520%255Ctext%257B%2520because%2520%257D%255Cmu%255CBig((1%252C2)%255CBig)%253D0%255C%255C%250AF(2)%2520-%2520F(1)%2520%2526%2520%253D%2520%255Cint_%257B(0%252C2)%257D%2520x%255C%252C%2520d%255Cmu%2520%2520-%2520%255Cint_%257B(0%252C1)%257Dx%2520%255C%252C%2520d%255Cmu%2520%255C%255C%250A%2526%2520%253D%2520%255Cint_%257B%255B1%252C1%255D%257D%2520x%255C%252Cd%255Cmu%2520%2520%2526%2520%255Ctext%257Bbecause%2520%257D%255Cmu((0%252C1))%253D0%253D%255Cmu((1%252C2))%252C%2520%255Ctext%257B%2520and%257D%2520%255Cmu(%255B1%252C1%255D)%253D1%255C%255C%250A%2526%2520%253D%25201%2520%250A%255Cend%257Baligned%257D?scale=1)

So \[\displaystyle \int_{(1,2)} x\,d\mu =0\neq x\bigg|_{1}^{2}=2-1=1\]%257D%2520x%255C%252Cd%255Cmu%2520%253D0%255Cneq%2520x%255Cbigg%257C_%257B1%257D%255E%257B2%257D%253D2-1%253D1?scale=1). What went wrong? Nothing. We simply used a measure where (([x_1,x_2])) and so a measurement that vanished for intervals no longer vanishes.

Always make sure you are using an interval measure when applying the Newton-Leibniz Theorem.
